# Environment Variables

Use these values in the hosting dashboards. Do not commit real secrets.

## Render Backend

Service: `hirematrix-backend`

```env
GEMINI_API_KEY=your_actual_gemini_key
GEMINI_MODEL=gemini-flash-latest
SECRET_KEY=generate_a_long_random_value
FRONTEND_ORIGIN=https://your-vercel-app.vercel.app
PYTHON_VERSION=3.11.11
```

Where to add them:

Render Dashboard > backend service > Environment > Add Environment Variable.

Notes:

- `GEMINI_API_KEY` is the only required external API key.
- `SECRET_KEY` can be generated by Render if you deploy from `render.yaml`.
- `FRONTEND_ORIGIN` should be your final Vercel URL. Use `*` only for quick testing.
- `PYTHON_VERSION` is already set in `render.yaml`.

## Vercel Frontend

Project: `frontend`

```env
HIREMATRIX_API_BASE=https://your-render-service.onrender.com
```

Where to add it:

Vercel Project > Settings > Environment Variables.

Use the Render URL without a trailing slash.
